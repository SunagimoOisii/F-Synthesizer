# GUI UX 構造的問題リスト

最終更新: 2026-02-26 (GUI UX #6 対応)
起点: `docs/SOUND_PARAMETERS.md` 作成時に発見されたユーザー向け説明が必要になった箇所

---

## 概要

このドキュメントは、ユーザー向けドキュメントを書く過程で露見した「GUI 構造に起因する使いにくさ」をまとめたものです。
「説明書を書かないと伝わらない」箇所は、GUI 側での解消候補でもあります。

---

## 1. Sound Slot の概念が UI に現れていない

**現状:**
Sound タブには "Selected Sound Slot (0-15)" という入力欄があるが、その意味・役割がラベルだけでは伝わらない。
チャンネルに 16 個のスロットがあること、スロット間の関係（独立した音色定義であること）が UI 上で説明されない。

**影響:**
初見ユーザーが「このスロットは何か」「どう使い分けるのか」を理解できない。ドキュメント側で補足が必要。

**改善候補:**
- スロット選択欄の横にツールチップまたは説明テキストを付与する
- スロット切替時に「Slot N / 16」のような文脈を表示する

---

## 2. Sound タブ / Music タブの役割分担が初見で不明

**現状:**
音量・パン・ミュート・ソロなどのミックス設定は Music タブにあり、Sound タブにはない。
ユーザーが「なぜ音量がここにないのか」と迷う可能性がある。

**影響:**
Sound タブを見てミックス設定を探しても見つからず、Music タブの存在を知らないユーザーは設定箇所を見失う。

**改善候補:**
- Sound タブの末尾またはヘッダに「ミックス設定は Music タブ」と案内を入れる
- タブ名を役割が伝わる表現（例: "Tone" / "Mix"）に変える

---

## 3. DrumKit の Type 選択に連動したパラメータ表示切替がない

**現状:**
DrumKit の各ノートで Type（Kick / Snare / Hat / None）を選択しても、すべての Kick・Snare・Hat パラメータが常に表示され続ける。
Type に対応しないパラメータも常時見えており、何が有効かをユーザーが自分で把握する必要がある。

**影響:**
Kick を選んでいるのに Snare/Hat のパラメータが並ぶ。設定ミスや混乱の原因になる。

**改善候補:**
- Type の選択値に応じて、対応するセクションだけを表示（または非対応パラメータをグレーアウト）する

---

## 4. DrumConfig の 0 = 未指定という内部規則が UI に露出している

**現状:**
DrumConfig の各パラメータは初期値が 0 だが、0 は「無効」や「無音」ではなく「内部デフォルトを使う」という意味を持つ。
この規則は UI 上では示されず、ユーザーは 0 が何を意味するか判断できない。

**影響:**
「0 を設定したら音が出ない」と誤解しやすい。また、実際の内部デフォルトがいくつかも UI では確認できない。

**改善候補:**
- 各パラメータのプレースホルダーまたはラベルに「0 = デフォルト」と明記する
- 内部デフォルト値をフィールドに初期表示し、ユーザーが明示的に設定した値と区別できるようにする

---

## 5. Waveform のフィルタが「デフォルトで有効」かつ見た目で判別しにくい

**現状:**
WaveformConfig の FilterMode の既定値は `Bypass` ではなく `LowPass`（Cutoff 8000 Hz）。
ユーザーがフィルタを設定した覚えがなくても、作成直後からフィルタが音に影響している。

**影響:**
「なぜか音がこもる」「設定していないのに音色が変わる」という状況が生まれやすい。

**改善候補:**
- FilterMode の既定値を `Bypass` に変更する（影響調査が必要）
- または、Filter が有効であることを視覚的に強調する（インジケーター、色変化など）

---

## 6. モジュレーションルートの名前が汎用的で内容を示さない

**現状:**
モジュレーションマトリックスの各ルートは "Route 0" 〜 "Route 3" と表示されるだけで、設定内容（LFO1→Pitch など）が折りたたんだ状態では見えない。

**影響:**
複数のルートを設定後、後から確認・変更する際に内容を把握するために全ルートを展開する必要がある。設定ミスに気づきにくい。

**改善候補:**
- ルートのヘッダに「Route 0: LFO1 → Pitch (0.5)」のような設定内容のサマリを表示する
- 有効なルートのみ色や記号で区別する
