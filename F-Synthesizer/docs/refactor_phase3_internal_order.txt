REFACTOR Phase 3 Internal Dependency Order

Goal
- Reduce direct dependency on src/SynthEngine/Internal.h outside SynthEngine implementation files.

Order
1) Lock internal ownership
- Internal.h can be included only from src/SynthEngine/*.cpp.
- App/GUI/Config/Midi/Core layers must use public headers only.

2) Isolate entry points
- Keep RenderGateway as the only core-side render call path.
- Avoid new direct calls to RenderMIDIEvents from app/gui.

3) Extract reusable DTOs if needed
- If non-SynthEngine layers need shared data, move minimal structs to include/SynthEngine/SynthEngine.h.
- Do not leak VoicesSoA/RenderState internals.

4) Narrow Engine.cpp dependencies
- Engine.cpp consumes Events/Renderer/Voices APIs but remains the single orchestrator.
- Prevent circular includes by preferring forward declarations in Internal.h where possible.

5) Validate and cleanup
- Build + CLI/GUI smoke after each step.
- Remove dead helpers and stale includes.
