# Tier 2: 音質・気持ちよさへの直接投資

最終更新: 2026-03-26

前提: Tier1（`tier1-expression-foundation.md`）は実装完了のため、本書を次の着手対象とする。

## 目的

- 音場（広がり）と質感（奥行き・厚み）を強化する
- 演奏ニュアンス（PitchBend運用）を実用レンジへ拡張する

## 3. ステレオレンダリング

### 実装タスク

- [ ] `AudioBuffer` をステレオ対応へ拡張（L/R分離）
- [ ] Mixer層で `ChannelMixState.pan` を L/Rゲインへ変換
- [ ] 既存パイプライン
  - `source render -> shaper -> mod -> mix`
  - を維持しつつ `mix/output` レイヤーのみL/R化する
- [ ] 出力書き出し経路（Preview/Writer）で2chを正しく処理する

### テストタスク

- [ ] `pan=0.0`（中央）で L/R 等量を確認
- [ ] `pan=-1.0/+1.0` で片側寄りを確認
- [ ] 既存モノラル想定設定でも破綻しないことを確認

### 完了条件

- [ ] ステレオWAV出力でパン定位が聴感・波形上ともに一致する
- [ ] 既存処理順の責務分離を壊していない

## 4. エフェクト層追加（Shaper後段 or 専用レイヤー）

### 実装タスク

- [ ] エフェクト挿入点を設計し、契約を明文化する
  - [ ] `common shaper後段` か `effect layer` を選択
- [ ] 第一弾として以下を追加
  - [ ] シンプルリバーブ（Schroeder/Moorer）
  - [ ] ディレイ（テンポ同期オプション）
  - [ ] コーラスまたはフランジャー
- [ ] パラメータ最小セット（mix/time/feedback等）を定義
- [ ] ステレオ前提での処理順とCPUコスト上限を決める

### テストタスク

- [ ] dry/wet 0..100% 端点で破綻しないことを確認
- [ ] feedback系で発散しないことを確認
- [ ] テンポ同期ディレイがBPM変更時に追従することを確認
- [ ] エフェクトOFF時に既存音との差分が最小であることを確認

### 完了条件

- [ ] 1プリセット内で空間感・厚みの改善が明確に確認できる
- [ ] 実時間再生で許容CPU範囲内に収まる

## 5. PitchBendレンジのRPN対応

### 実装タスク

- [ ] `RenderState` に `channelPitchBendRange[]` を追加
- [ ] RPN 0（Pitch Bend Sensitivity）受理処理を実装
  - [ ] RPN選択 (`CC101/100`)
  - [ ] Data Entry (`CC6/38`)
- [ ] 現状固定 `±2 semitone` をチャンネル可変へ置換
- [ ] 初期値は後方互換のため `±2` を維持

### テストタスク

- [ ] RPN未指定時に `±2` のままであることを確認
- [ ] `±12` 設定時に期待通りのベンド量になることを確認
- [ ] チャンネルごとの独立設定が機能することを確認

### 完了条件

- [ ] 一般的なMIDIシーケンスのRPNベンド設定に追従できる
- [ ] ベンド周りで既存回帰がない
