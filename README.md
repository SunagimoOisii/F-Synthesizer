# F-Synthesizer

手持ちの MIDI に好みの音色を割り当て、自分版の曲を作る Windows アプリです。
プリセットを選び、音の明るさ・荒さ・揺れ・鳴り方を調整し、曲として試聴して WAV に書き出せます。

## 起動

この PC でビルドする場合は、リポジトリ直下から実行します。

```powershell
.\F-Synthesizer\scripts\check.ps1
.\F-Synthesizer\build\x64\Debug\F-Synthesizer.exe
```

Visual Studio からは `F-Synthesizer.sln` を開き、`Debug | x64` でビルド・実行します。
別の PC の環境構築は [AGENTS.md](AGENTS.md) の「ビルド環境」を参照してください。

## MIDI から自分の曲を作る

1. **Compose** で MIDI ファイルを開きます。
2. チャンネル一覧の元の楽器名を参考に、変更したいチャンネルの **探す** を押します。
3. **Play** でプリセットを選び、**調整** のスライダーで好みに合わせます。
4. 単音の試聴や曲のプレビューで確認します。音量・左右の位置も調整できます。
5. **プロジェクト保存** で作業内容を保存します。
6. **Export** で出力先を指定して WAV を書き出します。

音源の細かい設定やエフェクトは **Advanced** にあります。
音色は FM・波形合成を中心に使えます。現在の FM は独自実装です。

## 音符とドラム

Compose のピアノロールでは、音符の追加・選択・移動・長さの調整ができます。
Undo / Redo は Ctrl+Z / Ctrl+Y です。
ドラムは通常チャンネル10を使い、ドラムセットのプリセットを選びます。
ピアノロールと16ステップのドラム入力を切り替えられます。

## 保存するもの

| 操作 | 保存内容 |
|---|---|
| プロジェクト保存 | 全音色、チャンネル割当、ミックス、編集した音符、画面状態 |
| 音色を別名保存 | 選択中の音色を、自分用の新しいプリセットとして追加 |
| WAV 書き出し | 現在の曲を音声ファイルとして出力 |

付属プリセットは編集の出発点です。選択すると編集用にコピーされます。
プロジェクト保存や音色の別名保存から、付属プリセットを上書きすることはありません。
同じ名前の自分用音色がある場合も、連番付きの新しいファイルを作ります。
Play / Advanced の「音色を戻す」でプリセット選択やマクロ調整を取り消せます。

作業状態は `F-Synthesizer/config/workspace.json` に保存され、次回起動時に復元されます。
自分用の音色は `F-Synthesizer/config/user_presets/` に保存されます。
入力 MIDI はファイルへの参照なので、後で再開する場合も元の MIDI を保管してください。

## 現在の制約

- 通常の曲再生は先読みレンダリングです。再生中の音色変更を即時反映する改修は未完了です。
- プロジェクトは現在、一つの作業状態を保存する方式です。曲ごとの名前付き保存は未実装です。
- 旧 `gui_state.json` と `piano_roll_project.json` は新しい保存形式へ自動移行しません。
- 対象は現在の Windows PC と、必要に応じた身内への配布です。
