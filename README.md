# F-Synthesizer

手持ちの MIDI に好きな音色を割り当て、自分版の曲を作る Windows アプリです。
FM 音源を中心に、プリセットの微調整、簡単な音符編集、WAV 書き出しができます。

## 起動

この PC では、リポジトリ直下の **[start.cmd](start.cmd) をダブルクリック**してください。
変更分をビルドして起動します。Visual Studio の画面を開く必要はありません。

- ビルドだけ: `.\start.cmd --build-only`
- ビルド済みのアプリだけを起動: `F-Synthesizer/build/x64/Release/F-Synthesizer.exe`
- ビルド環境を作り直す場合: [AGENTS.md](AGENTS.md)

## まず使ってみる

1. 右上の **… → MIDIを開く** で手持ちの曲を選びます。
2. **再生** を押し、上部から変えたいチャンネルを選びます。
3. 右の常設 **プリセット** 一覧で音を選び、**明るさ・ざらつき・余韻** を調整します。
4. **採用前と比較** で聴き比べ、気に入ったら **このchに採用**。**取り消す** で採用前へ戻せます。
5. **音量・消音・このパートだけ聴く** で曲のバランスを整えます。左右の位置は **左右** から開きます。
6. **保存** で `.fsynth` の曲ファイルへ保存し、**WAV** で音声を書き出します。

音色やミックスの変更は再生中にも反映されます。音声の先読みは約20msです。
実際に耳へ届くまでの時間には画面更新と音声デバイスのバッファも加わります。
音源の種類を切り替えた場合は、鳴っている音を新しい音源で発音し直します。

## 音色を選ぶ

付属プリセットは20個です。リード、ベース、鍵盤、パッド、ギター、効果音、
補助の電子音、2つのドラムセットを用意しています。

- 主旋律: **アーケード・リード**、**X68 リード**、**16bit ブラス**
- 低音: **16bit ベース**、**スラップ・ベース**
- 伴奏: **FM エレピ**、**ゲーム・オルガン**、**16bit ストリングス**
- ドラム: チャンネル10で **アーケード・ドラム** または **パワー・ドラム**

FM は ymfm の **YM2151 / YM2612** を使用しています。
**鳴り方・揺れ → 詳細** では音源の切替、4つのオペレーター、エフェクトなどを編集できます。
音源チップの制約に合わせ、FM の周波数比は0.5または整数1〜15、波形は正弦波です。
オペレーターのエンベロープの秒数は目安で、内部では段階的な値になります。

ノブは上下ドラッグで操作し、Shift で微調整、右クリックで数値入力、ダブルクリックで基準値へ戻せます。
普段の調整はプリセットの特徴を保つ範囲です。使えない項目は、その位置を空けて表示します。
付属音色には実音の測定に基づく音量補正を適用します。音域や奏法による差は残るため、音量でも調整できます。

**一音鳴らす** は曲のよく使う高さで試聴し、隣のボタンから高さと長さを変更できます。
ドラムセットでは **ビートを試聴** になります。再生中は曲を一時停止し、試聴後に同じ位置から戻ります。
波形は選択チャンネルの実音を表示し、**曲全体** へ切り替えられます。
上部の進行バーはクリックで移動、ドラッグで小節単位の区間リピートを指定します。

別のチャンネルへ移っても、試していた音で鳴り続けます。Aを調整してBを試し、Aへ戻ると調整したAを復元します。
**取り消す** で音色を戻しても、音量・左右の調整は残ります。
**いまの音を追加** は、調整した音を曲に依存しないお気に入りへコピーします。
下部の一覧で検索・分類・横スクロールができ、右クリックで名前を変更できます。
付属音色や、お気に入りの呼び出し元は、音色を編集しても変わりません。

## 音符とドラムの編集

- 空白をドラッグ: 音符を追加
- 音符をドラッグ: 移動。右端をドラッグ: 長さを変更
- Delete: 削除。Ctrl+Z / Ctrl+Y: 音符の取り消し・やり直し
- ホイール: 上下。Shift+ホイール: 左右。Ctrl+ホイール: 拡大・縮小
- 上の目盛をドラッグ: 再生範囲を指定。**再生範囲を解除** で全体に戻す
- Space: 再生・停止

**音符を編集** で中央をピアノロールへ切り替えます。編集は次の再生開始時に反映されます。
チャンネル10は **16ステップで編集** とピアノロールを切り替えられます。
16ステップは表示中の4拍を編集し、ほかの区間のドラムは残します。
ドラムの微調整はセット全体へ反映され、次の打音から変わります。

音色調整の **戻す / やり直す** と Ctrl+Z / Ctrl+Y は一操作ずつ戻す機能です。
未採用の音をまとめて戻す **取り消す** とは別です。

## 保存と再開

**保存 / 別名保存** は、全音色、チャンネル割当、ミックス、編集した音符と元の MIDI を
一つの `.fsynth` に保存します。**曲を開く** で再開でき、元の MIDI を移動しても復元できます。
Ctrl+S は保存、Ctrl+Shift+S は別名保存です。
未採用の音色がある場合、保存・WAV書き出しの前に **まとめて採用して続行 / 戻って調整** を選びます。

終了時の作業状態は `F-Synthesizer/config/workspace.json` に保存され、次回起動時に復元されます。
未採用の音色と、チャンネルごと・プリセットごとの微調整も復元します。
終了時の自動保存は、名前を付けた曲ファイルを上書きしません。
自分用音色は `config/user_presets/`、曲内 MIDI の作業用コピーは `config/song_cache/` にあります。
曲全体のリバーブなどは、右上の **… → 設定 → 曲全体の効果** から調整できます。

## 対応範囲

通常の MIDI ファイル（SMF format 0 / 1、拍に基づく時刻）に対応します。
SMPTE 時刻と format 2 は対象外です。音色の自動追従より、各チャンネルで選んだ音色を優先します。
旧方式の独自 FM 音色は、今回の音源で同じ音になることを保証しません。
録音素材・SoundFont の読込は今回の対象に含めていません。
