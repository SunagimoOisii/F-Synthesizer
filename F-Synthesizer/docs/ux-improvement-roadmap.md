# UX Improvement Roadmap — 初心者・楽しさ視点

> 方針根拠: `PRODUCT_POLICY.md`
> 「理論説明より触って音が変わる体験」「失敗しにくく短時間で気持ちよい結果に到達できる導線」

---

## 設計の核心

**「パラメータを設定する道具」→「音を探索する場所」へのシフト**

現状UIは「設定値を知っていれば使える」構造。
目標は「触ったら何かが変わる → それが気持ちいい」のループを作ること。

## Phase 1 — 即効性の高い改善（HIGH）

3層UX が動いた状態で「音との出会いをもっと楽しくする」追加投資。
Layer2 マクロスライダーを軸にした探索体験を完成させる段階。

### 1-A: 仮想キーボード

**目的:** 「シンセで弾ける」体験の確立。Layer2 でスライダーを動かしながら鍵盤で即確認する循環を作る。

- Sound タブ最下部にクリッカブルなピアノ鍵盤 UI を配置（C2〜C6）
- クリックで `tonePreviewNoteNumber` を更新し、即座に Tone Preview を発火
- 黒鍵・白鍵の区別を視覚的に表示
- DrumKit モード時は非表示（既存 `tonePreviewNoteNumber` の非表示ロジックと統一）

**受け入れ条件:**
- [ ] 全音域（少なくとも C2〜C6）をクリックで試聴できる
- [ ] DrumKit モード時は非表示

---

### 1-B: Randomize（Layer2 統合版）

**目的:** Layer2 マクロスライダーの値をランダム変化させる。全パラメータではなく「4本のマクロ軸」を起点とすることで結果が壊れにくい。

- `[Randomize]` を Layer2 パネル内またはその直下に配置
- 強度プリセット: Subtle / Medium / Wild
  - Subtle: 各マクロ値を ±0.1 以内でランダム変化
  - Medium: ±0.3
  - Wild: 0..1 の範囲で完全ランダム
- 実行前に `MacroSliderState` のスナップショットを保存（Undo 可能）
- 実行後に Auto Tone Preview をトリガー

**受け入れ条件:**
- [x] Subtle でマクロ4本が小さく変化し、音の雰囲気が保たれる
- [x] Wild で毎回明確に異なる音が出る
- [x] 実行後 Ctrl+Z で元のマクロ値に戻る

> **実装メモ:** `[元に戻す]` ボタンによる 1 段スナップショット復元で代替実装済み。  
> Ctrl+Z による完全 Undo は Phase 1-D で達成。

---

### 1-C: VU メーター

**目的:** 「ちゃんと音が出ているか」の即時確認。クリップ警告で音量ミスを気づかせる。実装コスト最小。

- Tone Preview / Play Preview 中にリアルタイムレベルメーターを表示
- ピーク超過時に赤ピークホールドを表示
- 既存 PCM バッファから最大振幅を取得するだけで実装可能

**受け入れ条件:**
- [x] 再生中にレベルが動的に変化する
- [x] クリップ（|sample| > 1.0）時に赤表示になる
- [x] 停止後もピーク値を数秒保持する

---

### 1-D: Undo/Redo（Sound エディタ）

**目的:** 「戻れない恐怖」が探索を止める最大の原因。Layer2 マクロ操作・Layer3 個別編集の両方を対象とする。

- Sound タブのパラメータ変更（Layer2/Layer3 共通）を履歴スタックに積む
- Ctrl+Z / Ctrl+Y で操作を元に戻す/やり直す
- ピアノロールの Undo/Redo とは独立したスタック
- セッション中のみ保持（ファイル保存は不要）
- 1-B（Randomize）のスナップショットもこのスタックに乗せる

**受け入れ条件:**
- [x] Layer2 スライダー操作後 Ctrl+Z で直前のマクロ値に戻る
- [x] Layer3 個別パラメータ変更後 Ctrl+Z で元に戻る
- [x] Ctrl+Y でやり直しができる

---

### 1-E: プリセット追加（JSON のみ）

**目的:** Layer1 タグフィルターの実効性を上げる。各タグにマッチするプリセットを揃えて「発見体験」を成立させる。

**スタートテンプレート（音源タイプ別出発点）:**
- Waveform: `Warm Pad / Bright Lead / Sub Bass`
- FM: `Bell / Electric Piano / 8bit Blip`
- Analog: `Acid Bass / Soft Brass`
- Noise: `Wind / Static`
- Drum: `808 Kick / Snare Hit`

**レトロゲームサウンドプリセット（MVP 直結）:**
- `FC_Triangle_Bass`（ファミコン三角波ベース）
- `FC_Square_Lead`（ファミコン矩形波メロディ）
- `GB_Noise_Drum`（ゲームボーイノイズ打楽器）
- `FM_Bell`（DX7 的ベル）
- `FM_Slap_Bass`（FM スラップベース）

**追加要件:**
- 各プリセット JSON の `tags` フィールドに Layer1 タグ名（英語キーワード）を付与
- 各プリセット JSON の `description` フィールドに音の特徴説明

**受け入れ条件:**
- [ ] Layer1 タグフィルターで各タグに少なくとも 1 件以上ヒットする
- [ ] 各プリセットに説明文が付いている

---

### 1-F: ホバー文言の継続改善

**目的:** Layer3 の専門用語をより音楽的な表現に。Tier C/D で追加されたパラメータのヘルプ欠落を解消する。

優先対象（Tier C/D 実装後に未整備のもの）:

| パラメータ | 改善後イメージ |
|---|---|
| `pulseWidth` | `音の細さ・鋭さ。LFOで揺らすとクラリネット的な揺らぎに` |
| `hardSyncEnabled` | `倍音の金属感を追加。クラシックなジッパーサウンドに` |
| `ringModEnabled` | `2つの音が干渉して生まれる金属的・ベル的な響き` |
| `lfo1.delayMs` | `音が鳴り始めてからビブラートがかかるまでの間 (ms)` |
| `modEnv.curve` | `変化の加速感。低いと急激に、高いとなだらかに変化` |
| `arpeggio.rateHz` | `音が繰り返す速さ。高いほど細かく刻む` |

**受け入れ条件:**
- [x] 主要導線（Filter / Envelope / LFO / Modulation / Arpeggio）でホバー文言欠落なし
- [x] `gui-help-hover-acceptance-checklist.md` に反映済み

## Phase 2 — 体験の深みを増す（MEDIUM）

Phase 1 完了後に着手。各タスクは独立して実施可能。

### 2-A: ADSR / LFO グラフィカル表示

**目的:** 「数値ではなく形で覚える」体験。エンベロープの概念を視覚で伝える。

- Envelope セクションの隣にカーブ描画エリアを追加（`ImGui::PlotLines` 拡張）
- A/D/S/R の数値変更時にカーブがリアルタイム更新
- LFO も全 `LfoWave` 列挙値（Square/Saw/SampleAndHold を含む）の波形プレビューを常時表示

**受け入れ条件:**
- [ ] A/D/S/R の数値変更時にカーブがリアルタイム更新される
- [ ] LFO 波形プレビューが全 `LfoWave` 列挙値に対応している

---

### 2-B: FM アルゴリズムのオペレーター接続図

**目的:** Algorithm 0〜7 の接続を図示。FM の理解を促進する。

- コンボボックス選択時、隣にオペレーター接続のブロック図を描画
- DX7 スタイル: Op 矩形 + 矢印（キャリア/モジュレーター関係を図示）
- `ImGui::DrawList` で描画（外部ライブラリ追加なし）

**受け入れ条件:**
- [ ] Algorithm 0〜7 全ての接続図が表示される
- [ ] コンボ変更時に即座に図が切り替わる

---

### 2-C: コードモード（仮想キーボード拡張）

**目的:** 1キーで和音を鳴らせる。理論を知らなくてもそれっぽいフレーズが出る。1-A 完了後に着手。

- キーボード上部に `Chord` トグルを配置
- コード種別: Major / Minor / 7th / Minor 7th / Sus4
- 選択したルートキー + コード構成音を同時に Tone Preview で発音

**受け入れ条件:**
- [ ] Chord OFF 時は従来の単音試聴と同じ動作
- [ ] Chord ON 時に指定コードの構成音が全て鳴る

---

### 2-D: タップテンポ

**目的:** 手拍子で BPM を合わせる直感操作。Delay tempoSync やアルペジオレートと連動させると即効性が高い。

- `[Tap]` ボタンを連打すると直近 4 打の間隔の平均から BPM を算出
- 算出した BPM を `masterTempo` に反映
- Music タブのテンポ表示エリアに配置

**受け入れ条件:**
- [ ] 4 回以上タップで安定した BPM が算出される
- [ ] 算出 BPM が Delay tempoSync とアルペジオレートに即座に反映される

---

### 2-E: 「書き出す」専用モード

**目的:** Export に集中した専用画面。「どこで WAV を保存するのか」を初心者に明確にする。

現行の `Export WAV` ボタンと出力パス設定を Music タブから分離し、書き出し専用の軽量ビューに集約する。

```
┌────────────────────────────────────────┐
│  出力先: [path/to/output.wav] [Browse] │
│  Format: 44100 Hz / 16bit / Stereo ▼  │
│                                        │
│  書き出し対象: (●) All  ( ) Ch10 のみ  │
│                                        │
│  [Export WAV]    [Play Preview]        │
│                                        │
│  VU: ████████░░░░ -1.2dB  [Stop]      │
│                                        │
│  最近の書き出し:                        │
│  2026-03-27 output.wav (3.2 MB)       │
└────────────────────────────────────────┘
```

実装時は `UIModeTab` を 0/1/2 に拡張し、既存の Sound/Music タブに 3 番目として追加する。

**受け入れ条件:**
- [ ] Export WAV が書き出し専用モードから実行できる
- [ ] 1-C（VU メーター）を流用できる

---

### 2-F: ドラムチャンネルのステップシーケンサービュー

**目的:** ピアノロールより直感的なリズム入力。`GUI_REQUIREMENTS.md` の「ドラム向け短縮導線」要件と一致。

- Music タブで ch10（ドラム）選択時に切替ボタンを表示（`Piano Roll` / `Step Seq`）
- 16ステップ × 主要パーカッション行（Kick/Snare/HH等）のグリッド

```
Kick  [■][ ][■][ ] [■][ ][■][ ]
Snare [ ][ ][■][ ] [ ][ ][■][ ]
HH    [■][■][■][■] [■][■][■][■]
```

**受け入れ条件:**
- [ ] ステップ編集結果が `Play Preview` / `Export WAV` に反映される
- [ ] ch10 以外では表示されない

---

### 2-G: エフェクトチェーン視覚化

**目的:** SampleRateReducer → Reverb までの順序と ON/OFF を一目で把握できる。

- 横並びのブロックチェーン図で各エフェクトを表示
- 各ブロッククリックで ON/OFF トグル
- OFF のブロックはグレーアウト、ON のブロックはハイライト
- `ImGui::DrawList` で描画（外部ライブラリ追加なし）

**受け入れ条件:**
- [ ] 全 6 エフェクト（SampleRateReducer → BitCrusher → Chorus → Flanger → Delay → Reverb）のブロックが表示される
- [ ] ブロッククリックで有効/無効が切り替わり、音に即座に反映される

---

### 2-H: プリセット間モーフィング（Layer2 統合版）

**目的:** 2つのプリセットの Layer2 マクロ値を補間。スライダーを動かすと音が変わる探索の目玉機能。

- `[Preset A]` と `[Preset B]` を選択し、`Morph` スライダー（0.0〜1.0）で Layer2 マクロ値を線形補間
- スライダー操作のたびに Auto Tone Preview をトリガー
- 原則として Layer2 マクロ軸の補間のみ行う（生パラメータ補間より結果が安定）

**受け入れ条件:**
- [ ] スライダー 0.0 で Preset A、1.0 で Preset B のマクロ値になる
- [ ] 中間値でクリップやサイレントにならない

---

### 2-I: ピアノロールのリフテンプレート

**目的:** 空プロジェクトでの「何から始めればいいか」問題を解消する。Music タブ初回の壁を下げる。

- `[Load Template]` から選択できる 2〜4 小節のスターターパターンを同梱:
  - `8bit Melody`（シンプルな単音メロディ）
  - `4 on the floor`（4 つ打ちキック）
  - `Simple Bass Line`（ルート音を中心にした単音ベース）
- 既存ノートへの上書き前に確認ダイアログを表示

**受け入れ条件:**
- [ ] テンプレート読み込み後 `Play Preview` でそのまま鳴らせる
- [ ] 既存ノートへの上書き前に確認ダイアログを表示する

## Phase 3 — 将来の差別化要素（LOW）

設計コストが高いか演出的な改善。Phase 2 完了後の候補。

### 3-A: タブ名変更 + UI モード再構成（[遊ぶ][作る][書き出す]）

当初 Phase 0 の目玉として計画していたが、3層UXの実装により
「発見（Layer1）→ 調整（Layer2）→ 詳細編集（Layer3）」の流れは Sound タブ内で達成済み。
タブ名変更は体験の方向感を伝えるために依然有効だが、2-E（書き出す専用モード）実装後に着手する。

### 3-B: モジュレーションルーティング図

LFO1 / Env2 / ModWheel → Filter Cutoff / Pitch / PulseWidth 等の接続を、線で結ばれたフロー図で表示。
現状 0〜7 のルートをテキストリストで管理しているが、全体像が見えにくい。
`DrawList` で動的レイアウトが必要なため実装コストが高い。

### 3-C: マクロスライダー拡張

> **→ `docs/codex-prompts-3layer-ux.md` の Layer 2 として実装済み。本項は拡張候補のみ記録する。**

追加候補: Layer2 スライダー設定（brightness/roughness 等のマッピング）をチャンネルごとに保存・読み込み可能にする。

### 3-D: ビジュアルテーマ（レトロゲーム風スキン）

ImGui スタイル設定で実装可能。ゲームボーイのグリーンモノクロ / ファミコン黒赤 / CRT スキャンライン風など。
機能的な改善ではないため最後の候補とする。

### 3-E: スケールスナップ（ピアノロール）

ノート配置を指定スケール（C major / A minor / Blues 等）に自動スナップ。
「音痴にならない」保証で初心者のメロディ作成の壁を下げる。

### 3-F: ADSR カーブの直接ドラッグ編集

2-A のカーブ表示を拡張し、グラフ上の点をドラッグしてパラメータを変更。

## タスク優先マップ

```
Phase 0（完了）  ← 3層UX（Layer1発見 + Layer2マクロ + Layer3詳細）+ 各種 Fix

Phase 1（HIGH）  ← 「弾ける・壊せる・戻せる・分かる」の基盤を固める
  1-A 仮想キーボード              ← 最優先。Layer2と組み合わせる体験の核
  1-B Randomize（Layer2統合版）  ← マクロ軸でランダム。壊れにくい探索
  1-C VU メーター                 ← 最小コスト・即効性最高
  1-D Undo/Redo（Layer2+Layer3） ← 失敗しにくさの保証。1-B と組み合わせる
  1-E プリセット追加（JSON）      ← Layer1 タグフィルターの実効性確保
  1-F ホバー文言改善              ← Tier C/D 追加パラメータの欠落を解消

Phase 2（MEDIUM）  ← 体験の深みを増す。各タスクは独立して着手可
  2-A ADSR/LFO 視覚化
  2-B FM アルゴリズム図
  2-C コードモード（1-A完了後）
  2-D タップテンポ
  2-E 「書き出す」専用モード
  2-F ドラムステップシーケンサー
  2-G エフェクトチェーン視覚化
  2-H プリセットモーフィング（Layer2統合版）
  2-I ピアノロールテンプレート

Phase 3（LOW）  ← 設計コストが高いか演出的な改善
  3-A タブ名変更 + UIモード再構成（2-E完了後に着手）
  3-B モジュレーションルーティング図
  3-C マクロスライダー拡張
  3-D ビジュアルテーマ（レトロスキン）
  3-E スケールスナップ（ピアノロール）
  3-F ADSR カーブ直接ドラッグ編集
```
