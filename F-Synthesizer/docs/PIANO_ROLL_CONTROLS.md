# PIANO_ROLL_CONTROLS

ピアノロールの操作方法を一覧化したリファレンス。
このファイルは `phase/task` とは分離し、日常的に参照する操作仕様として扱う。

## 基本編集（高頻度）

- クリック: ノート選択
- ドラッグ: ノート移動
- ノート端ドラッグ: ノート長変更
- 空白ドラッグ: ノート作成
- Shift+空白ドラッグ: 範囲選択
- Delete / Backspace: 選択ノート削除
- Ctrl+Z / Ctrl+Y: Undo / Redo

## ナビゲーション（高頻度）

- ホイール: 縦スクロール（音高）
- Shift+ホイール: 横スクロール（時間）
- Ctrl+ホイール: 時間ズーム

## 再生（高頻度）

- ルーラドラッグ: Preview範囲指定
- Space: Preview再生/停止

## スナップ

- Q: Snap ON/OFF
- 1/2/3/4: 1/4, 1/8, 1/16, 1/32

## UI方針

- 高頻度操作はキャンバス直接操作を優先
- 低頻度の数値調整UIは廃止
- 表示行数は空き領域に追従して自動調整
