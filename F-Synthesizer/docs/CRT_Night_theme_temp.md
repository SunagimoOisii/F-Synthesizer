# CRT Night Theme 検討メモ（破棄前提）

> 作成日: 2026-03-29
> 目的: 3-D（ビジュアルテーマ）実装前の比較メモ
> 扱い: 破棄前提の一時ドキュメント

## 前提

- 対象は `CRT Night + 走査線/ドット` の演出追加。
- まず可読性と操作性を優先し、演出は段階導入する。
- 常用を想定するため、初期値は「弱い演出」に寄せる。

## 候補案（再整理）

### A. Light CRT（実用重視）
- 構成: `CRT Night` 配色 + 薄い走査線のみ
- 長所: 可読性が高い、負荷が低い、導入が簡単
- 短所: インパクトは弱い
- 推定負荷: 低

### B. Classic CRT（王道）
- 構成: `CRT Night` 配色 + 走査線 + 軽いビネット
- 長所: CRTらしさが明確
- 短所: 画面端の視認性がやや落ちる
- 推定負荷: 低〜中

### C. Shadow Mask（ドットマスク）
- 構成: `CRT Night` 配色 + RGBドット/縦マスク
- 長所: 最もレトロ感が強い
- 短所: テキスト可読性低下、描画負荷上昇
- 推定負荷: 中

### D. Scanline Pulse（動き付き）
- 構成: `CRT Night` 配色 + 走査線 + ごく弱い時変（明滅/ゆらぎ）
- 長所: 通電感・ライブ感が出る
- 短所: 長時間利用で疲れやすい可能性
- 推定負荷: 中

### E. Hybrid Pixel（折衷）
- 構成: `CRT Night` 配色 + 走査線 + 低密度ドット
- 長所: 演出と可読性のバランス
- 短所: 調整パラメータが増える
- 推定負荷: 中

### F. Theme Stack（切替式）
- 構成: `CRT Night` 本体 + レイヤートグル（Scanline/Dot/Vignette）
- 長所: 調整自由度が高く将来拡張しやすい
- 短所: UIと状態管理の実装量が増える
- 推定負荷: 可変

## 優先順（実装推奨）

1. A. Light CRT
2. B. Classic CRT
3. F. Theme Stack
4. E. Hybrid Pixel
5. C. Shadow Mask
6. D. Scanline Pulse

## 優先理由

1. まず常用可能な品質を確保する必要がある（A）。
2. 次に「CRTらしさ」を上げる（B）。
3. その後、ユーザー調整可能な構造を入れる（F）。
4. ドット系と動き系は可読性・疲労・負荷の観点で後回し（E/C/D）。

## 導入ステップ（段階的）

### Step 1（最小）
- `CRT Night` カラーパレット適用
- 走査線 ON/OFF（強度固定）

### Step 2（実用）
- ビネット追加（弱）
- 走査線強度スライダー（0〜30%）

### Step 3（拡張）
- Dot Mask ON/OFF
- Dot 密度/強度の簡易設定

### Step 4（演出）
- 時変エフェクト（Pulse）を任意ON
- デフォルトOFF維持

## 受け入れ基準（簡易）

- 文字可読性: 既存テーマ比で明確な悪化がない
- 操作性: 小UI要素（チェックボックス/スライダー）の視認性を維持
- 負荷: 通常操作で体感劣化なし
- 退避: テーマOFFで従来表示に即復帰できる

## 実装時の注意

- 走査線/ドットは濃度を低く始める（初期値は弱）
- ドットは高密度にしない（描画負荷・可読性悪化）
- 演出は必ず個別トグル可能にする
