# OUTPUT_RULES.md — 出力規約

## コード出力

- 新規ファイルはパスを示してから提示する。
- 既存ファイルは差分中心で示す。
- 言語付きコードブロックを使う。

## 説明出力

- 実装方針を先に簡潔に述べる。
- 冗長な説明や重複説明を避ける。
- 不確実な事項は未確認と明示する。

## コメント規約

- `src/` と `include/` のコメントは `agents/standards/COMMENT_GUIDELINE.md`（必須版）を適用する。
- 詳細規定が必要な場合のみ `agents/standards/COMMENT_GUIDELINE_FULL.md` を参照する。
