# PIANO_ROLL_DIRECT_INTERACTION_PHASES

ピアノロールを「スライダー中心の間接操作」から「キャンバス直接操作」へ移行するためのフェーズ定義。

## 目的

- 頻繁に使う操作ほど、少ない手順で実行できる状態にする
- マウス中心で編集を完結できるようにする
- 既存の Preview / Export 経路との互換を維持する

## 操作優先度（高 -> 低）

1. ノート選択 / 移動 / 長さ変更
2. 空白からのノート作成
3. 縦横スクロール
4. 時間ズーム
5. Preview開始/停止
6. スナップ切替
7. 低頻度の詳細調整（従来UI）

## PHASE_1_CORE_EDIT_DIRECT

Status: DONE

- 左クリックで選択
- ドラッグで移動
- 端ドラッグで長さ変更
- 空白ドラッグでノート作成
- Shift+空白ドラッグで範囲選択

完了条件:
- 編集の主要操作がキャンバス上のみで完結する

## PHASE_2_NAVIGATION_DIRECT

Status: DONE

- ホイールで縦スクロール
- Shift+ホイールで横スクロール
- Ctrl+ホイールで時間ズーム
- ズーム中心をマウス位置に固定

完了条件:
- スライダーなしでも視点操作が成立する

## PHASE_3_PLAYBACK_DIRECT

Status: DONE

- ルーラクリックで再生開始位置変更
- SpaceでPreview再生/停止
- 既存の再生成ポリシー（Musicは常に再生成）を維持

完了条件:
- 編集 -> 試聴 の往復がキーボード1キーで回せる

## PHASE_4_SNAP_AND_SHORTCUT_POLISH

Status: DONE

- Snapの常設トグルをキャンバス付近へ配置
- QでSnap ON/OFF、1/2/3/4で分解能切替
- 現在値は常設トグル表示で確認する（オーバーレイは使わない）

完了条件:
- スナップ系操作が1アクションで切り替え可能

## PHASE_5_LEGACY_UI_MINIMIZE

Status: DONE

- 低頻度スライダー/詳細設定UIを廃止
- 直接操作と重複するUIを縮小
- 初心者向けの案内文を更新
- ピアノロール表示行数を空き領域へ追従拡張し、ログ展開時も自動調整
- ルーラの列番号ラベルに最小間隔を設け、数字つぶれを防止

完了条件:
- 常用導線が直接操作中心に整理される

## PHASE_6_USER_GUIDE

Status: DONE

- 利用者向け操作ドキュメント `docs/USER_PIANO_ROLL_GUIDE.md` を新規作成
- 内容は「最初の5分」「基本編集」「ショートカット」「よくあるつまずき」を含める
- 直接操作仕様（本ドキュメント / `PIANO_ROLL_CONTROLS.md`）と整合する

完了条件:
- 直接操作導入後の最新仕様で利用者が手順を追える
