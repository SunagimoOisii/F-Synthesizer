# USER_PIANO_ROLL_GUIDE

ピアノロールを初めて使う人向けの操作ガイドです。  
対象は現行実装（Phase 1-5完了時点）です。

## 最初の5分

1. `Music` タブを開く
2. `MIDI Path` でMIDIを選ぶ
3. ピアノロール上でマウスホイールを回して上下に移動する
4. `Space` で試聴開始、もう一度 `Space` で停止する
5. ルーラ（上部の目盛り）をドラッグして、試聴範囲を指定する
6. Snap は `Q`（ON/OFF）と `1/2/3/4`（1/4,1/8,1/16,1/32）で切り替える

## 基本編集

- ノート選択: ノートを左クリック
- ノート移動: ノートをドラッグ
- ノート長変更: ノート右端付近をドラッグ
- ノート追加: 空白をドラッグ
- 範囲選択: `Shift` を押しながら空白をドラッグ
- ノート削除: ノートを選択して `Delete` または `Backspace`
- Undo/Redo: `Ctrl+Z` / `Ctrl+Y`

## ショートカット

- `Space`: Preview 再生/停止
- `Q`: Snap ON/OFF
- `1`: Snap 1/4
- `2`: Snap 1/8
- `3`: Snap 1/16
- `4`: Snap 1/32
- `Delete` / `Backspace`: 選択ノート削除
- `Ctrl+Z`: Undo
- `Ctrl+Y`: Redo

## よくあるつまずき

- 再生範囲が思った位置でない  
  : ルーラをドラッグし直してください。

- ノートが細かく合わない  
  : `Q` で Snap をONにし、`1/2/3/4` で分解能を調整してください。

- ノートが見つからない  
  : ホイールで上下スクロールし、表示範囲を移動してください。

- 画面下部に余白が見える/表示が変わる  
  : ログ開閉やウィンドウサイズに合わせて表示行数は自動調整されます。
