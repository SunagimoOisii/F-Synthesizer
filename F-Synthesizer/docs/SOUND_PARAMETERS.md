# Sound タブ パラメータガイド

最終更新: 2026-02-26

各チャンネルの **Sound タブ** で調整できるパラメータの一覧と、それぞれが合成音声に与える影響を説明します。

> **Sound Slot について:** Sound タブでは 0〜15 の **Sound Slot**（音色定義）を編集します。MIDI Channel（ch）がどの Slot（s）を使うかは Music タブの Assignment（`ch -> s`）で設定します。画面上部の "Selected Sound Slot (0-15)" で編集対象の Slot を切り替えてください。このドキュメントは 1 Slot 分のパラメータを説明しています。

## 1. 合成方式の選択

チャンネルごとに以下の4方式から1つを選べます。

| 方式 | 用途のイメージ |
|---|---|
| **Waveform** | リード、ベース、パッドなど音程のある音全般 |
| **FM** | ベル、EP系、金属的・デジタルな音 |
| **Noise** | ノイズテクスチャ、空気感、効果音 |
| **DrumKit** | MIDIノート番号ごとに Kick / Snare / Hat を割り当てたドラムセット |

方式を変えると **Sound タブに表示されるパラメータが切り替わります**。
セクション2の共通パラメータはどの方式でも常に有効です。

## 2. 共通パラメータ（全方式共通）

### 音量（Amp）

| パラメータ | 説明 |
|---|---|
| **Amp** | チャンネルの基本音量。値を上げると大きくなります。 |

### ADSR エンベロープ

鍵盤（MIDIノート）を押した瞬間から離した後まで、音量がどのように変化するかを制御します。

```
音量
 ↑   /\
 |  /  \___________
 | /   D    S      \
 |/ A               \ R
 +--------------------------→ 時間
```

| パラメータ | 意味 | 音への影響 |
|---|---|---|
| **Attack** | 音が最大音量に達するまでの時間 | 短い：打楽器のような立ち上がり。長い：フェードインするような柔らかな出だし |
| **Decay** | 最大音量からサステインレベルまで下がる時間 | 短い：素早く落ち着く。長い：余韻がある |
| **Sustain** | 鍵盤を押している間の音量レベル（0〜1） | 0に近い：押した直後にほぼ消える（プラック系）。1に近い：ずっと鳴り続ける |
| **Release** | 鍵盤を離してから無音になるまでの時間 | 短い：ピタッと止まる。長い：余韻が残る |

> **Note:** 音量・パン・ミュート・ソロなどチャンネルのミックス設定は **Music タブ** で行います。Sound タブは音色定義のみを扱います。

## 3. Waveform（基本波形）

音程のある音を作るための汎用合成方式です。シンプルな正弦波から、ユニゾンやフィルタを組み合わせた複雑な音まで幅広く対応します。

### 3.1 波形（Wave）

| 設定値 | 音の特性 |
|---|---|
| **Sine** | 倍音を含まない純粋な音。柔らかく、まろやか |
| **Square** | 奇数倍音のみを含む。中音域でパワフル、中空感がある |
| **Saw** | 全倍音を含む。明るく、リッチで存在感がある。リードやベースの定番 |
| **Triangle** | 奇数倍音のみだが Sine に近い柔らかさ。Square より穏やか |

---

### 3.2 Unison（ユニゾン）

複数の仮想オシレータを同時に動かして音を厚くする機能です。

| パラメータ | 範囲 | 音への影響 |
|---|---|---|
| **Voices** | 1〜8 | 同時発音ボイス数。増やすほど音が厚く豊かになる。1のときはユニゾンなし（最も軽い） |
| **Detune** | 0〜120 cent | ボイス間の音程ずれ幅。小さい値（2〜5cent）でわずかなゆらぎ・温かみ。大きい値でコーラス・デチューン感が強まる。大きすぎると音程感が崩れる |
| **Spread** | 0.0〜1.0 | ボイス間の位相をどれだけ分散させるか。0はモノラルに近い。1に近いほどステレオ感が広がる |

---

### 3.3 Sub-Oscillator

メインの波形より **1オクターブ低い音** を混ぜる機能です。

| パラメータ | 範囲 | 音への影響 |
|---|---|---|
| **Sub Osc Level** | 0.0〜2.0 | 0で無効。0.6〜1.0あたりで低域が補強され、ベースに太さや重みが出る。上げすぎると低域が膨らみすぎる |

---

### 3.4 フィルタ（Filter）

音の周波数成分を削ったり強調したりして、音色のキャラクターを整えます。

**フィルタモード**

| モード | 動作 | 代表的な使い方 |
|---|---|---|
| **Bypass** | フィルタをかけない（素通し） | フィルタ不要のとき |
| **Low Pass** | 設定周波数より高い成分を削る | 音をこもらせる・暖かくする。シンセの定番 |
| **High Pass** | 設定周波数より低い成分を削る | 低域をカットしてすっきりさせる |
| **Band Pass** | 設定周波数の周辺だけ残す | 特定の帯域を強調する |

**フィルタパラメータ**

| パラメータ | 範囲 | 音への影響 |
|---|---|---|
| **Cutoff (Hz)** | 10〜20000 Hz | カットオフ周波数。LowPass なら下げるほど音が暗くなる。ADSR やモジュレーションと組み合わせて時間変化させることで典型的なシンセサイザーのフィルタースイープ効果が得られる |
| **Resonance** | 0.1〜18.0 | カットオフ付近の共鳴の強さ。高いほどカットオフ周波数でピークが立ち、エッジが効いたクセのある音になる。高すぎると自己発振気味になる |

---

### 3.5 スムージング（Smoothing）

パラメータが切り替わるときの変化を滑らかにして、クリックノイズや急峻な変化を防ぎます。

| パラメータ | 範囲 | 音への影響 |
|---|---|---|
| **Smoothing 有効** | ON / OFF | スムージング機能全体の有効化 |
| **Pitch Smoothing 有効** | ON / OFF | ピッチスムージングだけ個別に有効化 |
| **Amp Time (ms)** | 0〜1000 ms | 音量変化の滑らか時間。値が大きいほどゆっくり音量が変わる |
| **Pitch Time (ms)** | 0〜1000 ms | ピッチ変化の滑らか時間。連続した音程変化をつなぐポルタメント効果が得られる |
| **Filter Cutoff Time (ms)** | 0〜1000 ms | フィルタカットオフ変化の滑らか時間。フィルタスイープを滑らかにする |

---

### 3.6 LFO1（Low Frequency Oscillator）

音を周期的に揺らすための低周波発振器です。単体では音は出ず、後述の **モジュレーションマトリックス** と組み合わせて使います。

| パラメータ | 範囲 | 説明 |
|---|---|---|
| **Wave** | Sine / Triangle | LFO の波形。Sine は滑らかな揺れ、Triangle は直線的な揺れ |
| **Rate (Hz)** | 0〜100 Hz | LFO の速さ。低い値（〜5Hz）でビブラートやトレモロ。高い値で音色変調的な効果 |
| **Depth** | 0.0〜1.0 | LFO の深さ（出力のスケール）。揺れの大きさを決める |
| **Bipolar** | ON / OFF | ON: -1〜+1 の対称な揺れ（ビブラート向き）。OFF: 0〜1 の片側だけの揺れ（トレモロ向き） |

---

### 3.7 Env2（第2エンベロープ）

音量とは別に、モジュレーション用として使える独立した ADSR エンベロープです。LFO1 と同様、モジュレーションマトリックスと組み合わせて使います。

| パラメータ | 説明 |
|---|---|
| **Attack** | モジュレーションが最大値に達するまでの時間 |
| **Decay** | 最大値からサステインレベルへ下がるまでの時間 |
| **Sustain** | 鍵盤を押し続けている間のモジュレーション量 |
| **Release** | 鍵盤を離してからモジュレーションが消えるまでの時間 |

---

### 3.8 モジュレーションマトリックス（4ルート）

LFO1 または Env2 の出力を、ピッチ・音量・フィルタのどれかに接続して変調します。GUI では "Route 0" 〜 "Route 3" として縦に4つ並んで表示され、それぞれに以下のパラメータがあります。

| パラメータ | 選択肢 | 説明 |
|---|---|---|
| **有効** | ON / OFF | このルートを使うかどうか |
| **Source（変調源）** | None / LFO1 / Env2 | 何を使って変調するか |
| **Destination（変調先）** | None / Pitch / Amp / Filter Cutoff | 何を変調するか |
| **Amount** | -1.0〜1.0 | 変調の深さと向き。正で正方向、負で逆方向に変調する |

**設定例**

| Source | Destination | 効果 |
|---|---|---|
| LFO1 | Pitch | ビブラート（音程を周期的に揺らす） |
| LFO1 | Amp | トレモロ（音量を周期的に揺らす） |
| LFO1 | Filter Cutoff | フィルタワウ（フィルタを周期的に揺らす） |
| Env2 | Filter Cutoff | フィルタスイープ（ノートオン時にフィルタを時間変化させる） |
| Env2 | Pitch | ピッチスイープ（ノートオン時に音程を時間変化させる） |

## 4. FM（2オペレータ FM 合成）

**キャリア**（出力する波形）と**モジュレータ**（キャリアの位相を変調する波形）の2つのオシレータを使った周波数変調合成です。倍音が豊かに変化し、金属的・デジタル的な音が得意です。

| パラメータ | 説明 | 音への影響 |
|---|---|---|
| **Carrier Wave** | キャリアの波形（Sine / Square / Saw / Triangle） | 出力波形の基本的なキャラクター |
| **Mod Wave** | モジュレータの波形（Sine / Square / Saw / Triangle） | 変調パターンの形状。Sine が最も素直な FM サウンド |
| **Carrier Ratio** | キャリアの周波数比（基音に対する倍率） | 音程の基本を決める |
| **Mod Ratio** | モジュレータの周波数比（基音に対する倍率） | モジュレータ周波数の比。整数比で倍音的、非整数比で非整数倍音が生まれ金属的になる |
| **Index（変調指数）** | 変調の深さ | 最も重要なパラメータ。0で変調なし（キャリアの素の音）。大きくするほど倍音が増えて明るく複雑になる |
| **Out Level** | FM 音源の出力レベル | 最終的な音量の倍率 |

**Index の目安**

| Index の値 | 音のイメージ |
|---|---|
| 0〜0.5 | 倍音が少なく柔らかい |
| 0.5〜2.0 | 中程度の倍音感。EP やベル的 |
| 2.0〜5.0 | 倍音豊かで明るく、金属感が出る |
| 5.0 以上 | 非常に複雑な倍音構造。ノイジーになりやすい |

## 5. Noise（ノイズ）

ランダムなノイズを生成する合成方式です。音程を持たず、テクスチャや空気感の付与、効果音などに使います。

| パラメータ | 選択肢 | 音への影響 |
|---|---|---|
| **Noise Type** | White / Pink / Brown / Blue | ノイズの周波数特性を決める |

**ノイズタイプの特性**

| タイプ | 周波数特性 | 音のイメージ |
|---|---|---|
| **White** | 全帯域に均等にエネルギーが分布 | ザラつきのある明るいノイズ。最も一般的 |
| **Pink** | 高域に向かって −3dB/oct で減衰（1/f 特性） | 自然界の音に近い。柔らかく聴きやすいノイズ |
| **Brown** | 高域に向かって −6dB/oct で減衰（1/f² 特性） | 低域が豊かで重い。波の音・風のような印象 |
| **Blue** | 高域ほどエネルギーが多い（White の逆） | シャープで刺激的な高域寄りのノイズ |

ノイズ固有のパラメータは Noise Type のみです。音量の時間変化は共通の ADSR で制御します。

## 6. DrumKit（ドラムキット）

MIDI ノート番号 0〜127 の各ノートに対して、Kick / Snare / Hat のパラメータを個別に設定できる方式です。1チャンネルで複数種類のドラム音を MIDI ノートで使い分けられます。

### 6.1 ノートの選択

| 操作 | 説明 |
|---|---|
| **DrumKit Note (0-127)** | 編集対象のノート番号を切り替える。選択中のノートに以下のパラメータが適用される |

---

### 6.2 各ノート共通パラメータ

| パラメータ | 説明 |
|---|---|
| **Type** | Kick / Snare / Hat から選択。None を選ぶとそのノートは無音 |
| **Gain** | そのノートのドラム音全体の音量 |

すべてのパラメータが Type に関わらず常に表示されます。Type ごとに実際に合成へ使われるパラメータは 6.3〜6.5 節を参照してください。

各パラメータの既定値は 0 です。0 のままのパラメータは Type ごとの内部デフォルトが適用されます（0 が「無効」や「無音」を意味するわけではありません）。

---

### 6.3 Kick

サイン波のピッチを急激に下降させることで、電子キックドラムの「ドン」という音を合成します。

| パラメータ | 説明 | 音への影響 |
|---|---|---|
| **Base Freq (Hz)** | 打撃直後の初期周波数 | 高いほど高ピッチなキック。一般的に 60〜120 Hz 付近 |
| **Pitch Drop** | ピッチの降下倍率（1.0 = 変化なし） | 大きいほど音程が大きく落ちる。「ドーン」感が強まる |
| **Pitch Decay (sec)** | ピッチが降下しきるまでの時間 | 短い：タイトで速いキック。長い：ルーズで深みのあるキック |

---

### 6.4 Snare

波形（トーン成分）とノイズを混合し、ハイパス・ローパスフィルタで整形して、スネアドラムの音を合成します。

| パラメータ | 説明 | 音への影響 |
|---|---|---|
| **Tone Freq (Hz)** | トーン成分（ピッチ感）の周波数 | 高いほど明るくカラッとした音になる |
| **Tone Level** | トーン成分の混合量 | 上げるとピッチ感が増す。シンセドラム的になる |
| **Noise Level** | ノイズ成分の混合量 | 上げると「シャッ」というスネアらしい質感が強くなる |
| **Tone Wave** | トーン成分の波形（Sine / Square / Saw / Triangle） | 音のキャラクターを変える |
| **Noise Type** | ノイズの種類（White / Pink / Brown / Blue） | ノイズの質感を変える |
| **HP Cut (Hz)** | ハイパスフィルタのカットオフ周波数 | 高くすると低域をカットしてシャープな音になる |
| **LP Cut (Hz)** | ローパスフィルタのカットオフ周波数 | 低くすると柔らかく、高くすると明るくなる |

---

### 6.5 Hat（ハイハット）

高域ノイズとトーン成分を組み合わせ、ハイパス・ローパスフィルタで高周波帯域に絞り込んで、シンバル・ハイハットの音を合成します。

| パラメータ | 説明 | 音への影響 |
|---|---|---|
| **Tone Freq (Hz)** | 金属感を出すトーン成分の周波数 | 8000〜12000 Hz 付近が典型的なハイハット感 |
| **Tone Level** | トーン成分の混合量 | 上げるとリング感・金属感が増す |
| **Noise Level** | ノイズ成分の混合量 | 上げるとノイジーな質感が強まる |
| **Tone Wave** | トーン成分の波形 | Square が金属的で典型的 |
| **Noise Type** | ノイズの種類 | White / Blue が高域が多くハット向き |
| **HP Cut (Hz)** | ハイパスフィルタのカットオフ周波数 | 高くするほどシャープでシャリシャリした音になる |
| **LP Cut (Hz)** | ローパスフィルタのカットオフ周波数 | 高くするほど明るく鮮明になる |
