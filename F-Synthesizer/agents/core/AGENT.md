# AGENT.md — エージェント定義
## 目的（Purpose）
このエージェントは、以下を目的とする。
1. 指示範囲内で安全に実装を進める。
2. 変更とドキュメントの整合を維持する。
3. 「音の気持ちよさ」と即時試聴体験を優先して機能判断する。
4. 初心者が迷いにくい UI/操作導線を優先する。

## 非目的（Non-Goals）
このエージェントは、以下を行わない。
1. 承認なしの破壊的操作（履歴改変、無差別削除）。
2. 指示されていない大規模リファクタリング。
3. 非自動更新ファイルの無承認変更。
4. 高度DAW機能・プロ向け深いパラメータ・プラグイン対応・共同編集の先行実装。
5. 合成方式間での責務重複実装（境界は `docs/synth-methods/method-boundaries.md` を優先）。

## 成功の定義
1. 実装が要求を満たし、既存動作を壊さない。
2. 変更内容が追跡可能で、関連ドキュメントが更新される。
3. ルール違反なく作業が完了する。
4. 追加機能が「音の気持ちよさ」または試聴体験の改善に直接寄与する。

## 行動原則
優先順位:
1. 安全性
2. 正確性
3. 可読性
4. 効率性
基本方針:
- 不明点は推測で埋めず確認する。
- 失敗時は原因仮説を示し、同一コマンドの無修正リトライを避ける。
- 変更は最小単位で行う。
- 指示と整合しない実装は承認なしで進めない。

## 出力規約
コード出力:
- 新規ファイルはパスを示してから提示する。
- 既存ファイルは差分中心で示す。
- 言語付きコードブロックを使う。
説明出力:
- 実装方針を先に簡潔に述べる。
- 冗長な説明や重複説明を避ける。
- 不確実な事項は未確認と明示する。
コメント規約:
- `src/` と `include/` のコメントは `agents/standards/COMMENT_GUIDELINE.md`（必須版）を適用する。
- 詳細規定が必要な場合のみ `agents/standards/COMMENT_GUIDELINE_FULL.md` を参照する。

## ドキュメント運用
自動更新対象:
1. `docs/Architecture.md`
2. `docs/STATUS.md`
3. `docs/DECISIONS.md`
STATUS 運用:
- `docs/STATUS.md` を進捗管理の正本として運用する（`Current` / `Next 3` / `Blockers`）。
情報保持ポリシー:
- 短期情報（次回週次まで）: `docs/STATUS.md`
- 長期判断: `docs/DECISIONS.md`
- 長期契約: `docs/synth-methods/foundation-contract.md`
- ADR詳細: `docs/architecture/*.md` の `Special Notes`
非自動更新ファイル:
- 上記以外は直接変更しない。
- 変更が必要な場合は提案し、承認後に更新する。
提案テンプレ（非自動更新ファイル）:
```text
---
📋 提案制ファイルの更新提案
- 対象: <path>
- 要約: <何を変えるか>
- 理由: <なぜ必要か>
- 影響: <影響範囲>
承認 / 却下 / 修正 をお願いします。
```
更新後の報告:
- ドキュメントを更新した場合、変更ファイルと要約を作業報告に記載する。
